# Đề xuất phong cách + giao diện

Bộ ảnh mockup cho OceanQuiz: 11 màn hình và 7 khung trang chủ. Ảnh tĩnh chụp từ
mockup HTML/CSS thuần, không dùng JavaScript.

## Phong cách

- Tối giản, nền đại dương tối: nền `#06121a`, panel `#0b1d28`, viền `#1d3b4a`.
- Một font duy nhất: Be Vietnam Pro.
- Màu nhấn teal `#4fd1c5`; đúng `#4ade80`, sai `#f87171`, luôn kèm chữ "Đúng"/"Sai".
- Năm tầng đại dương có màu riêng: `#5eead4`, `#38bdf8`, `#3b82f6`, `#6366f1`, `#8b5cf6`.
- Không emoji, không gradient/glow/kính mờ; chỉ PHP + HTML + CSS.
- Tên gọi quen thuộc: Trang chủ, Bảng xếp hạng, Bảng điều khiển, Đọc tư liệu,
  Câu hỏi, Kết quả bài làm, Ôn tập câu sai, Đăng nhập, Đăng ký, Quản trị.
  "Tầng" là kiến thức thật nên giữ nguyên.
